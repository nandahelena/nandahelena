## Projetos em destaque

### RedRun

Sistema web desenvolvido para digitalizar auditorias da competição Red Bull 24 Horas.

**Contribuições:**

- Documentação técnica completa;
- WAD — Web Application Document;
- Wireframes e definição de fluxos;
- User Stories com critérios de aceitação em Gherkin;
- Diagramas UML de sequência.

### SheTech Hackathon

Identidade visual e direção de design para um hackathon feminino de tecnologia organizado pelo Coletivo Grace Hopper na Inteli.

**Contribuições:**

- Desenvolvimento do logotipo;
- Definição de paleta de cores e tipografia;
- Criação de materiais digitais e impressos;
- Direção visual baseada no conceito “Soft Innovation”;
- Desenvolvimento de uma narrativa visual com inspiração sci-fi.

### Portfólio pessoal

Portfólio front-end desenvolvido com Next.js e TypeScript, com foco em design editorial, acessibilidade e interação.

**Destaques:**

- Acessibilidade baseada nas diretrizes WCAG;
- Filtros por categoria;
- Animações de scroll reveal;
- Cursor customizado;
- Interface responsiva.
